# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public GitHub issue.

Report security concerns privately to **santanu@iconwizard.in** with:

- A concise description of the issue
- The affected page, component or workflow
- Reproduction steps, where appropriate
- The potential impact
- Any suggested remediation

Do not include real customer documents, credentials or personal data in the report.

## Public showcase policy

This repository must contain only synthetic, anonymised or explicitly approved public material. Secrets, OAuth tokens, API keys, connection strings, customer documents and customer-specific configurations must remain outside this repository.
